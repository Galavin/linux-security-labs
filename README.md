# Linux Security Labs (Pet-проект)

Этот репозиторий содержит Bash-скрипты, написанные в рамках изучения администрирования Linux и анализа логов.

## 1. mini-siem.sh (Детектор SSH-брутфорса)
Скрипт анализирует системный журнал (`journalctl`) и выявляет множественные неудачные попытки входа по SSH.
*   Логика: Если за последние 5 минут зафиксировано более 3 ошибок `Failed password`, скрипт выводит сообщение об атаке.
*   Использованные технологии: Linux, Bash, journalctl, grep, wc.

## 2. web-siem.sh (Детектор веб-сканирования)
Скрипт анализирует логи веб-сервера Nginx (`access.log`) и ищет аномалии.
*   Логика: Если зафиксировано более 3 запросов с кодом `404 Not Found`, это расценивается как сканирование скрытых директорий (например, `/.env` или `/admin.php`).
*   Использованные технологии: Nginx, Bash, grep.
