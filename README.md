# Linux Security Labs (Pet-проект)

Этот репозиторий содержит Bash-скрипты, написанные в рамках изучения администрирования Linux и анализа логов.

## 1. mini-siem.sh (Детектор SSH-брутфорса)
Скрипт анализирует системный журнал (`journalctl`) и выявляет множественные неудачные попытки входа по SSH.
*   Логика: Если за последние 5 минут зафиксировано более 3 ошибок `Failed password`, скрипт выводит сообщение об атаке.
*   Использованные технологии: Linux, Bash, journalctl, grep, wc.

## 2. web-siem.sh (Детектор веб-сканирования)
Скрипт анализирует логи веб-сервера Nginx (`access.log`) и ищет аномалии.
*   Логика: Если зафиксировано более 3 запросов с кодом `404 Not Found`, это расценивается как сканирование скрытых директорий (например, `/.env` или `/admin.php`).
*   Использованные технологии: Nginx, Bash, grep.

## 3. Docker (Собственный образ веб-сервера)
В папке представлены файлы для сборки кастомного Docker-образа на базе Nginx.
*   **Dockerfile:** Инструкция для сборки (базовый образ Nginx + копирование своего HTML).
*   **index.html:** Кастомная веб-страница, которая заменяет стандартную заглушку Nginx.
*   **Как запустить:** `docker build -t my-custom-site .` и `docker run -d -p 8080:80 my-custom-site`.
*   **Использованные технологии:** Docker, Nginx, HTML.

## 4. Docker Compose (Мультиконтейнерный стек)
В файле `docker-compose.yml` описан полноценный стек для веб-приложения и мониторинга.
*   **Сервисы:** Nginx (веб-сервер), PostgreSQL (база данных), Prometheus (сбор метрик), Grafana (визуализация), Node Exporter (метрики железа).
*   **Volumes:** Настроено сохранение данных для базы данных PostgreSQL (данные не теряются при пересоздании контейнера).
*   **Сети:** Сервисы общаются друг с другом по внутренним именам Docker.
*   **Как запустить:** `docker compose up -d`

## 5. Мониторинг (Prometheus + Grafana)
*   Файл `prometheus.yml` описывает конфигурацию сбора метрик с самого Prometheus и Node Exporter.
*   В Grafana настроен дашборд для визуализации нагрузки на CPU, RAM и диски.

## 6. Автоматизация (Ansible)
*   Файл `ansible-setup.yml` содержит плейбук для автоматической установки базовых утилит (htop, curl, git) и проверки статуса службы Nginx.
*   **Как запустить:** `ansible-playbook -i inventory ansible-setup.yml -K`

## 7. Логирование (Loki + Promtail)
*   **Loki:** Сервис для агрегации и хранения логов (аналог Elasticsearch, но легче).
*   **Promtail:** Агент, который собирает логи Nginx с виртуалки и отправляет их в Loki.
*   **Интеграция с Grafana:** Настроен источник данных для просмотра логов и поиска ошибок (например, кодов ответа 404) прямо в веб-интерфейсе.
*   **Стек:** Grafana Loki, Promtail.
